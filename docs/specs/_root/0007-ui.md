# UI aplikasi

**Status**: Implemented and verified within recorded scope
**Date**: 2026-09-16

## Summary
Implementasi keputusan yang disetujui pengguna. Cakupan AC: UI-001, UI-002, USER-001, PASSKEY-001.

## Requirements dan design
Sumber desain adalah komponen/tema resmi @ojiepermana/angular22.1.13, bukan library baru atau patch lokal. LayoutWrapperDefault + navigation dipakai dashboard dan halaman authenticated. LayoutFluidComponent dengan form ditengah dipakai login/aktivasi/pemulihan. Brand Foundation dan bahasa Indonesia. Tokens library mengendalikan warna, radius, spacing dan typography; design.md mencatat komposisi.

UI-001: /login email/password dan passkey, /activate#token, /forgot-password, /reset-password#token, /dashboard guarded, /profile, /users admin. Dashboard sapaan dari session User.name dan placeholder eksplisit tanpa angka bisnis palsu. Navigasi Dashboard/Profil/Pengguna(admin), logout. Session dipulihkan melalui API, bukan localStorage token. HTTP interceptor meneruskan CSRF hanya ke API same origin dan menghapus state ketika401.

Profil menampilkan nama/email/role, edit nama, ganti password, daftar/add/delete passkey dengan reauthentication. Users list mencari dan paginasi server, edit nama/role/status, validasi/error ditampilkan. Tidak ada tombol pembuatan user publik; registrasi CLI.

UI-002: loading, kosong, error dan success ditampilkan. Field berlabel, fokus terlihat, pesan error aria-live, tombol disabled selama submit, semua aksi dapat dipakai keyboard. Layout berfungsi pada lebar375 dan desktop1440 tanpa overflow dokumen. Browser tanpa passkey mendapat fallback password. Passkey dibatalkan memberi pesan ramah dan bisa dicoba lagi.

## Decision
Kontrak di atas disetujui dalam rencana Foundation. Default berasal dari rencana dan konfigurasi aplikasi; secret berasal dari environment.
