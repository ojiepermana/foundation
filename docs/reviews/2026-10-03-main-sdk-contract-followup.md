## Nits

- ⚪ `scripts/lib/api-artifacts.ts:58` dan `:26`, larangan `node_modules` pada target symlink dan daftar nama yang dilewati `cp` mencocokkan nama secara peka huruf besar kecil, sedangkan macOS (dan Windows) memakai filesystem yang tidak peka. Reviewer membuktikannya di mesin ini: symlink `scripts/l -> ../Node_Modules/pkg/index.js` diterima `copyApiInputs`, dan di workspace dengan symlink `node_modules` isinya terbaca (`package-content`) dari file checkout. Akibatnya kalimat spec ("satu satunya symlink lain di workspace, `node_modules`, tidak pernah dilewati") dan aturan lebih kuat daripada yang ditegakkan di macOS. Jaminan utamanya tetap berlaku: bentuk itu hanya mencapai isi `node_modules` karena `..` sesudah nama biasa ditolak, jadi `.env` tidak terjangkau. Untuk `skippedName`, reviewer hanya membaca kodenya (file `.ENV` atau `.Env` tidak cocok dengan `.env` dan akan ikut tersalin) dan tidak menjalankan probe; dampaknya kecil karena tahap Bun memakai `--no-env-file` dan tahap `node` tidak membaca `.env`. Bandingkan nama dalam huruf kecil untuk `node_modules` pada `staysInside`, dan untuk `.env`, `dist`, dan `.angular` pada `skippedName`, atau tulis batas ini di spec dan laporan bukti. Laporan bukti sudah mencatat batas serupa untuk specifier impor (`../../SDK`), jadi satu kalimat tambahan cukup.
- ⚪ `scripts/lib/api-check.ts:111`, hanya SIGINT dan SIGTERM yang ditangani. Karena `spawn` dengan `detached: true` membuat session baru, menutup terminal (SIGHUP) mematikan `api:check` tetapi membiarkan group `api:sync` berjalan dan folder `foundation-api-check-*` tertinggal. Pertimbangkan SIGHUP dengan exit 129 dan catat sebagai tambahan spec. Butir ini sudah ada di review sebelumnya dan belum ditindaklanjuti.
- ⚪ `scripts/lib/api-artifacts.ts:20`, `API_OUTPUTS` diekspor sesuai spec tetapi tidak dipakai di mana pun, sedangkan `scripts/lib/api-check.ts:18` menulis daftar `outputs` sendiri dan `readArtifacts` menulis ulang path SDK. Pakai satu sumber, atau hapus ekspor itu dan ubah baris *Modul artefak* di spec. Butir ini sudah ada di review sebelumnya.
- ⚪ `docs/specs/0009-sdk-sesuai-kontrak-backend/index.md:24`, AC-7 menulis hasil run pertama "disalin" ke `run1/`, sedangkan `keepFirstRun` (`scripts/lib/api-check.ts:47`) memindahkannya dengan `rename` supaya run kedua mulai kosong. Selaraskan kata di spec lewat `/architect` atau `/sync`. Butir ini sudah ada di review sebelumnya.
- ⚪ `docs/rules/openapi-sdk.md:32`, pohon `Lokasi file` memuat `check-api.ts` dan `vitest-backend.setup.ts` tetapi belum memuat `scripts/lib/api-check.ts`, `scripts/lib/api-artifacts.ts`, `scripts/lib/process-group.ts`, `apps/frontend/vitest-base.config.ts`, dan `apps/frontend/vitest-provided-context.d.ts`. Butir ini sudah ada di review sebelumnya dan cocok dikerjakan bersama `/document`.
