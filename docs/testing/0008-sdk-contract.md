## Batas bukti

- Kontainer Linux berjalan pada aarch64 lewat Docker Desktop di macOS. Linux x86_64, arsitektur runner GitHub `ubuntu-24.04`, belum dijalankan; CI menjalankan seluruh suite ini lewat `test:ci`.
- Checker bundle hanya membaca deklarasi impor dan ekspor. Nilai SDK yang keluar lewat konstanta atau nilai kembali method bergantung pada kontrak adapter dan review fitur pemilik. Symlink di bawah `apps/frontend/src` dan `apps/frontend/dist` kini ditolak, bukan dilewati, tetapi specifier absolut atau varian huruf besar kecil seperti `../../SDK` tetap tidak dihitung sebagai impor ke SDK.
- Harness bergantung pada Angular 22.2 yang memanggil `globalSetup` dua kali; pembaruan Angular dapat mengubahnya, dan asersi satu baris `listening` akan menunjukkannya.
- Asersi SDK-002 dan SDK-005 mencocokkan teks compiler (`TS2322` dan nama file) dan pesan penolakan generator. Versi Angular atau `@ojiepermana/angular` yang lebih baru dapat mengubah teks itu.
- Urutan manifest pada SDK-005 dibandingkan dengan urutan code unit; dengan nama file huruf kecil saat ini, urutan itu sama dengan urutan locale `en_US`, sehingga test tidak menunjukkan pembanding mana yang dipakai generator.
- Spec AC-7 menulis hasil run pertama "disalin" ke `run1/`; implementasi memindahkannya dengan rename sehingga run kedua dimulai kosong sesuai invariant 3, dengan byte yang sama di `run1/`.
- Sinyal yang tiba sesudah baris laporan tercetak tetap membuat `api:check` keluar 130 atau 143; pernyataan "tanpa baris laporan" hanya dibuktikan untuk sinyal yang tiba selama tahap berjalan.
- `Process group did not stop` dibuktikan dengan `ps` pengganti yang melaporkan group tetap hidup, dan `SDK contract backend did not stop` dengan `ChildProcess.prototype.kill` yang dibuat tidak bekerja. Proses nyata yang tidak dapat dihentikan SIGKILL tidak dapat dibuat di test, dan jalur `api:check` yang mencetak `API check failed` sesudah error itu tidak dijalankan ujung ke ujung.
- Test `rm` yang gagal memakai folder tanpa izin tulis, yang tetap dapat dihapus root. Test itu dilewati dan dilaporkan dilewati bila berjalan sebagai root, misalnya di kontainer Docker; runner GitHub dan run macOS di atas berjalan sebagai user biasa.
- Aturan symlink kanonik juga menolak bentuk yang sebenarnya tetap di dalam root, misalnya `../scripts/../.env`. Tidak ada symlink di input checkout saat ini.
- Test batas waktu SDK-010 mengandaikan `sdk:generate` pengganti memulai proses cucu dalam 2.000 ms; pada runner yang jauh lebih lambat asersi file pid dapat gagal sebelum perilaku AC-10 dipersoalkan.
- Pemindaian AC-9 mencari nilai sentinel, path, dan host tertentu di artefak; itu bukan pemindaian secret umum.
- Build frontend masih memberi warning anggaran initial bundle 500 kB yang sudah ada sebelum fitur ini.
- Dua direktori temp yang lebih tua dari pekerjaan ini (`foundation-db-test-*` dan `foundation-openapi-cli-*`) masih ada di `TMPDIR` dan tidak berasal dari run di atas.
- `/check verify`, `/test`, review kode, perbaikan temuan, review ulang, dan `/document` sudah dijalankan, dan gate akhir lulus pada 2026-10-04. Perbaikan review belum diulang di kontainer Linux. Lima nit dari [review ulang](../reviews/2026-10-03-main-sdk-contract-followup.md) tetap terbuka sebagai tindak lanjut: pencocokan nama `node_modules`, `.env`, `dist`, dan `.angular` pada `copyApiInputs` yang peka huruf besar kecil padahal filesystem macOS tidak, SIGHUP yang tidak ditangani `api:check`, `API_OUTPUTS` yang diekspor tanpa dipakai, kata "disalin" pada AC-7, dan pohon *Lokasi file* di `docs/rules/openapi-sdk.md` yang belum memuat modul baru. Laporan ini adalah bukti fitur, bukan bukti kesiapan release.
